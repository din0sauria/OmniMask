# 项目思路：面向多模态数据的隐私脱敏系统-OmniMask

使用uv管理环境，python版本为3.12，代码尽量符合人类书写习惯，不需要很规范，变量名不要过长，不需要太多注释，每次做的修改在保证功能的前提下，尝试用最少的改动实现。

一、核心思路
代码仓库、多模态隐私数据（文本图片视频）脱敏，可以考虑word，excel，ppt，pdf等格式文件的处理，支持的模态种类可以慢慢加。
已有开源的nlp命名实体识别模型和脱敏模型。
参考技术选型：FastAPI + Next.js

二、核心功能设计
1. 数据接入模块
支持多种输入方式：
- 文件上传：txt、csv、json、jpg、png、mp3、wav、mp4等；
- 批量导入：文件夹（代码仓库）；
2. 敏感信息检测模块
这是系统的核心，需要按模态分别设计。
文本检测：
- 识别姓名、手机号、身份证号、邮箱、地址、银行卡号；
- 可选拓展正则规则，识别企业敏感字段，如合同编号、财务数据、内部账号；
- 使用 NER、正则规则、字典匹配、上下文判断。
图像/视频检测：
- 人脸、人体、车牌、二维码、条形码；（不解码直接脱敏）
- 屏幕内容、工牌、文件编号、涉密标识；
- OCR 识别图像中的文本，再做 PII 检测。
音频（含视频中的音频）检测：
- 声纹特征保护；
- 将语音转文本后检测敏感信息；
3. 脱敏策略管理模块
用户不应只看到“自动打码”，而应能选择策略：
- 标准脱敏：默认策略；
- 自定义脱敏：自定义脱敏的种类；
- 可逆脱敏：通过授权密钥还原，适合需要保留代号给第三方进行数据分析，再将分析结果的代号还原的场景；
- 不可逆脱敏：彻底删除或混淆，适合公开数据。
4. 敏感信息处理模块
文本：
- 删除/打码（截断）/代号或随机值替换/加密/数字偏移和取整
图像/视频：
- 打码
音频（含视频中的音频）：
- 对音频做变声、片段静音。
5. 审核与导出模块
脱敏完成后，不应直接强制导出，而应提供审核环节：
- 展示原始数据与脱敏后数据对比；
- 高亮被处理区域；
- 允许人工确认、撤销、调整；
- 导出时生成脱敏报告，包括策略版本、处理时间、操作人、数据用途。
三、交互流程设计
1. 首页工作台
用户进入后看到：
- “新建脱敏任务”；
- “最近任务”；
- “策略模板”；
2. 新建任务流程
用户操作步骤可以是：
1. 上传数据；
2. 选择数据类型：文本 / 图片 / 音频 / 视频 / 混合；
3. 选择脱敏策略：标准 / 自定义；
4. 点击“开始检测”；
5. 系统展示检测结果；
6. 用户确认或调整；
7. 导出
3. 检测结果预览页
页面可以分为三栏：
- 左侧：原始数据；
- 中间：脱敏预览；
- 右侧：检测结果列表。
4. 策略配置页
策略配置建议做成可视化表单：
- 文本：姓名、电话、身份证、地址、邮箱、银行卡是否脱敏；
- 图像：人脸、车牌、二维码、屏幕、工牌是否处理；
- 音频：声纹保护、敏感词静音；
- 视频：是否处理背景文本；
- 阈值：置信度低于多少需要人工确认；
- 自定义配置：正则表达式。
