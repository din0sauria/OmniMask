# 项目规范：OmniMask 多模态隐私脱敏系统

> 当前里程碑：先只做代码（密钥/敏感串）检测，复用 keyleak 打通完整链路；文本 PII、图像、音视频等模态在主链路跑通后逐步接入。本文档描述的是目标架构。

## 1. 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Python 3.12 + FastAPI |
| 前端 | Next.js |
| 包管理 | uv（Python）、pnpm/npm（前端） |
| 检测模型 | ModelScope / GitHub 开源模型（HaS_Text、HaS_Image、gliner-pii 等） |
| 参考 baseline | Microsoft Presidio、gitee desensitize |

## 2. 目录结构

```

│   │   ├── main.py            # FastAPI 入口

│   │   │   ├── detect/        # 检测：text / image / audio / video / code
│   │   │   ├── mask/          # 脱敏处理：text / image / audio / video
│   │   │   └── policy/        # 策略管理
│   │   └── utils/
│   ├── tests/
│   └── pyproject.toml
├── frontend/
```

## 3. 编码约定

- Python 3.12，使用 uv 管理环境（`uv add` 装依赖，`uv run` 运行）。
- 代码尽量符合人类书写习惯，变量名不要过长，不写多余注释。
- 每次修改在保证功能的前提下，用最少的改动实现。
- 后端接口统一返回 `{code, msg, data}` 结构；异步任务用后台任务 + 轮询状态。
- 本地应用：任务只记录本地路径，源文件原地读取，不复制、不移动、不上传。
- 文件存储走本地 `data/` 目录，按任务 id 分文件夹，仅保存任务元数据与检测结果。
- 各模态的检测/脱敏逻辑独立成模块，接口统一为 `detect(input, policy) -> findings` 和 `mask(input, findings, policy) -> output`，方便逐步扩展模态。

## 4. 核心模块规范

### 4.1 数据接入
- 只接受本地文件或目录的绝对路径，后端原地读取，源文件只读。
- 提供只读目录浏览接口 + 前端弹窗，支持盘符切换、上一级、路径跳转、筛选与文件/目录选择。
- 新建任务表单提供默认值：路径名作为任务名、系统用户作为操作人、默认用途与标准策略；记住最近路径。
- 支持单文件或文件夹（代码仓库）导入；目录导入跳过 `.git`、`node_modules` 等。
- 任务创建时记录路径、文件清单与策略快照；不保存源文件副本。

### 4.2 已有模块复用
- `keyleak/`：已有代码仓库密钥检测工具，直接作为代码模态的检测能力复用：
  - `get_strings/`：多语言源码字符串提取（js/go/java/json/csv/ipynb 等），复用其提取逻辑作为代码文件的预处理；
  - `data/regex/`：现成正则规则库（merged_rules.json、http_regex.json 等），合并进文本检测的规则引擎；
  - `hit_git_tf.py` / `main.py`：命中检测主流程，封装为 detect 服务的 code 检测器；
  - `llmdetect.py`（LLM 辅助检测）依赖 Qwen2.5-Coder-7B，作为可选增强，默认关闭。
- keyleak 代码尽量不改原逻辑，通过在后端写薄封装层调用。

### 4.3 敏感信息检测
- 文本：NER + 正则 + 字典匹配 + 上下文判断；识别姓名、手机号、身份证、邮箱、地址、银行卡；支持自定义正则识别企业字段。
- 代码：复用 keyleak 检测密钥、token等硬编码敏感信息。
- 图像/视频：人脸、人体、车牌、二维码、条形码、屏幕内容、工牌、涉密标识；OCR 后再做文本 PII 检测。
- 音频：声纹特征检测；ASR 转文本后检测敏感信息。

### 4.4 模型管理
- 模型统一从 ModelScope 下载（`modelscope` SDK 或 git lfs），存放于项目根目录 `models/`，按模型名分子目录，如：
  - `models/HaS_Text_0209_0.6B_Q8`：文本 PII 检测；
  - `models/HaS_Image_0209_FP32`：图像敏感目标检测；
  - `models/gliner-pii-edge-v1.0`：轻量 PII NER（CPU 备选）。
- `models/` 加入 .gitignore，不进仓库；首次运行时检查本地是否存在，缺失则自动下载或提示手动下载。
- 检测模块通过统一的模型加载入口读取 `models/` 路径，模型路径写在配置里可改。
- 大模型（如 Qwen2.5-Coder-7B）默认不下载，仅在配置中显式开启 LLM 增强时才需要。

### 4.5 脱敏策略
- 四种策略：标准脱敏 / 自定义脱敏 / 可逆脱敏（密钥还原）/ 不可逆脱敏。
- 策略以 JSON 配置存储，包含：各类型开关、置信度阈值、自定义正则。

### 4.6 脱敏处理
- 文本/代码：删除 / 打码（截断）/ 代号或随机值替换 / 加密 / 数字偏移取整。
- 代码脱敏在内存中计算，不写回源文件；导出时按当前结果即时生成脱敏文件。
- 可逆映射由任务结果实时生成，不落盘独立映射文件。
- 图像/视频：打码。
- 音频：变声、片段静音。

### 4.7 审核与导出
- 展示原始与脱敏后对比，高亮处理区域；
- 支持人工确认、撤销、调整；
- 导出时生成脱敏报告（策略版本、处理时间、操作人、数据用途）。

## 5. 接口约定（主要）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/tasks | 新建任务（本地文件/目录路径） |
| GET | /api/tasks | 任务列表 |
| GET | /api/tasks/{id} | 任务详情/状态 |
| POST | /api/tasks/{id}/detect | 开始检测 |
| GET | /api/tasks/{id}/findings | 检测结果列表 |
| POST | /api/tasks/{id}/mask | 执行脱敏 |
| POST | /api/tasks/{id}/review | 审核确认/调整 |
| GET | /api/tasks/{id}/export | 导出结果 + 报告 |
| GET/POST | /api/policies | 策略模板管理 |

## 6. 前端页面

1. 首页工作台：新建脱敏任务 / 最近任务 / 策略模板；
2. 新建任务流程：填本地路径 → 选数据类型 → 选策略 → 开始检测 → 确认调整 → 导出；
3. 检测结果预览页：三栏（原始数据 | 脱敏预览 | 检测结果列表）；
4. 策略配置页：可视化表单（各模态开关、阈值、自定义正则）。
