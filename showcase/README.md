# OmniMask 测试样例与结果展示

本目录用于展示 OmniMask 的**测试样例（输入）**与**测试结果（输出）**，方便直接复测或演示“检测 → 审核 → 脱敏预览 → 导出”链路。样例为合成数据，仅用于功能验收，不代表真实数据分布或识别准确率。

## 目录结构

```
showcase/
├── samples/        # 16 组基础测试样例（文本/代码/图片/音频/视频/元数据/混合）
├── results/        # 测试记录与结果（31 项功能总表、语音专项、JSON 结果、说明）
└── screenshots/    # 浏览器实际验收截图（历史记录）
```

## 如何使用

1. 按仓库根目录 `README.md` 启动前后端（`start.ps1`）并准备好本地 ASR 模型（`scripts/download_asr.py`，音频/视频样例需要）。
2. 在工作台把 `samples/` 下的文件/目录作为本地路径创建任务，选择相应策略（文本 PII / 媒体脱敏）检测。
3. 逐条审核后生成预览、导出，与 `results/` 中的记录对照。
4. 语音专项细节参考 `results/修复与测试说明.md`；完整的 38 个冻结 WAV 与 benchmark 脚本未随本展示目录附入，如需复现见其文末说明。
